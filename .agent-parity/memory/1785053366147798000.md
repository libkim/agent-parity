agent-parity의 update는 설치 버전과 목표 버전을 입구에서 비교해 같으면 관리 상태를 전혀 변경하지 않고 성공 종료한다. 버전이 다를 때에는 install과 동일한 관리 파일 수렴·경고·tombstone 파이프라인을 실행한다. 동일 버전에서 손상 복구가 필요할 때 reinstall, uninstall, status 중 무엇을 사용할지는 사용자가 선택한다.
