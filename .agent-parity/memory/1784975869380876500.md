Windows에서 Linux 릴리스 게이트를 재현할 때 작업 트리를 Docker에 직접 마운트하거나 통째로 복사하지 않는다. scripts/test-release-container.ps1가 모든 변경이 staged됐는지 확인하고 Git 인덱스 스냅샷만 archive하므로 .git, dist, .cache와 미추적 파일이 제외된다. Git for Windows의 archive도 core.autocrlf에 따라 PS1/README를 CRLF로 내보낼 수 있으므로, 컨테이너의 일회성 사본에서 알려진 텍스트 형식만 LF로 정규화한 뒤 Unix 릴리스 테스트 전체를 실행한다. Go 모듈/빌드 캐시는 전용 Docker volume으로 재사용하고 다운로드는 일시적 네트워크 실패에 대비해 재시도한다.
