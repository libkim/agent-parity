Windows update 회귀 수정 체크포인트: 실행 중 agent-parity.cmd 교체는 원격 update 구간을 cmd 괄호 블록으로 선파싱해 안전하게 완료하도록 수정했고, PowerShell Write-Text와 Go config writer는 기존 LF/CRLF 규칙을 보존하도록 수정했다. 체크인된 Codex 설정은 기본 approve 정책의 정규 템플릿과 일치시키고 .gitignore 관리 블록에서 폐기된 memory/dist ignore를 제거했다. Windows 런처 교체, PowerShell 줄바꿈, 체크인 릴리스 상태 회귀 테스트를 추가했다.
